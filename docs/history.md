# 변경 이력

## 2026-10-09

- Tailscale 연결 옵션 중복을 제거하고, 연결 후 별도 명령으로 실행기의 서브넷 경로 수신을 해제했다.

## 2026-10-08

- 배포 작업에 Tailscale OIDC 연결과 SSH 전용 접근 설정을 추가했다.
- main/dev 별 GitHub Actions 배포와 독립 Compose를 추가했다.
- 비밀값을 환경변수 참조로 분리하고 공통·운영·개발 properties를 추가했다.
- 카카오 콜백과 초대 링크를 새 프론트엔드 주소에 맞췄다.
- Docker 테스트 단계에 Redis를 제공하고 운영·개발 설정 로딩을 검증했다.
- 수정 시각 테스트에서 대기와 미래 시각 대입을 제거하고 DB flush 후 수정 시각 갱신을 검증했다.
- 테스트 JWT 키를 운영 값과 분리했다.
