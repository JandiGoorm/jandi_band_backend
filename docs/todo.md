# 남은 작업

- 프론트 담당자 배포가 준비되면 카카오 로그인·콜백·화면의 이미지 흐름을 함께 검증한다. 프론트 수정은 현재 백엔드 작업 범위 밖이다.
- 공개 URL의 `+` 인코딩 수정을 dev에 배포하고 실제 S3 특수문자 경로를 재검증한 뒤 main 전환 PR을 진행한다.
- 1차 객체 복사 후 최종 전환 직전에 쓰기·삭제 배치를 멈추고 DB 백업·객체 검증·URL 대응표를 새로 만든 뒤 운영 DB URL을 전환한다.
- 전환 후 남은 S3 참조와 삭제된 객체의 공개 URL·CDN 캐시를 확인하고, 관찰 기간 이후 원본 정리와 이전용 권한 회수를 진행한다.
