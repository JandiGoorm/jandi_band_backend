# 남은 작업

## 이미지 저장소 배포 확인

- 이미지 오류 수정과 R2 전용 설정 변경을 dev/main에 순서대로 병합·배포하고, 배포 SHA와 실제 API 업로드·조회·삭제를 확인한다. 테스트 통과만으로 운영 배포가 완료된 것은 아니다.
- 운영 배포 확인 후 사용자가 원본 S3 버킷을 삭제한다. 삭제 직전 원본 목록에 새 객체가 없는지 확인하고, 사용하지 않는 AWS 자격증명과 이전 공개 URL 변수도 수동 환경 파일에서 정리한다. 자격증명을 다른 서비스가 사용하면 해당 권한을 구분한다.

## 프론트엔드 후속 확인

- 프론트 담당자 배포가 준비되면 카카오 로그인·콜백·화면의 이미지 흐름을 함께 검증한다. 프론트 수정은 현재 백엔드 작업 범위 밖이다.
